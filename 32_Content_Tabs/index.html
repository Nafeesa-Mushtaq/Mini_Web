Learning Notes

01 / STRUCTURE

Give the page a shape.

HTML describes the content of a page. Headings, paragraphs, lists, and links all have their own elements.

<h1>Hello, world!</h1>

02 / STYLE

Make it your own.

CSS controls color, spacing, type, and layout. A few clear rules can make a page much easier to read.

h1 { color: teal; }

03 / INTERACTION

Let the page respond.

JavaScript handles actions and updates content. Start with a button, a click event, and one small change.

button.addEventListener('click', greet);
